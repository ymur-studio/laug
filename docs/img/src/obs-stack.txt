desc | Left: each leased cell's own Prometheus, which dies with its cell, and bin/obs follow, which writes a target
desc | file a cell with the labels that outlive it. Middle: the stack's store federates each cell every 5 s and keeps
desc | the cell's own timestamps; with track_timestamps_staleness true a series the cell stops serving goes stale at the
desc | next pass, not 5 minutes on. It scrapes cellstat, follow, the host and the orchestrator's dev server too. Bottom:
desc | workflow Gate's worker and starter send traces over OTLP to the Collector, which hands them to Jaeger. Right:
desc | Grafana reads both. Every address is 127.0.0.1 (_obs/prometheus.yml, _obs/collector.yaml, _obs/jaeger.yaml).
