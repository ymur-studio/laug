title | The Firecracker pool's network: a namespace a clone, held by its own process
sub | Two microVM cells, blocks 0 and 1, restored from one snapshot: one machine inside, apart outside
desc | Two cells of the microVM pool, blocks 0 and 1, each a firecracker process in network and mount namespaces that
desc | only it holds. laugfc<b> on the host and veth0, 10.254.<b>.2, inside the cell's namespace are the two ends of a
desc | veth pair. Inside, a DNAT rule sends what the host sends to 10.254.<b>.2 on through tap0 to the guest, whose
desc | address is the same in every clone, so two guests never meet. The guest can start one kind of connection: to the
desc | host's SDK metrics ports, 9091 to 9093. Deny rules on the host drop anything forwarded to or from laugfc+. Arrows
desc | run the way a connection from the host goes.
