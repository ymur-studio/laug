desc | Above, one lease. A requester, a person with laug lease or laug raun, asks laug pool serve for a cell. The pool
desc | builds cells warm before anyone asks and hands one over. The leased cell is a Temporal server of its own: every
desc | role, and its own Postgres behind toxiproxy. laug load runs Omes on it. laug fault holds a fault on it and reads
desc | it before, during and after. Released, the cell is destroyed, and the pool builds warm cells back up to its -min.
desc | Below, one gate. laug gate run starts a pool of its own, which builds a fresh cell for each of its three leases.
desc | Three items run at once: incumbent, the release the tag replaces, under the load; steady, the release under the
desc | same load; pl, the release with Postgres slowed by a fault. Each writes its files under gate/results/<gate id>/.
desc | The judge, laug judge, reads them: ADVANCE only when every rule from R1 to R7 holds, else BLOCK, naming the rule
desc | that decided.
