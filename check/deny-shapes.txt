# The shapes bin/obs pack refuses in a pack of the store and the traces (_obs/cmd/obs/doc.go, pack). One extended
# regular expression a line, as grep -E reads it, over every byte of every file the pack holds, and over the store's
# and the trace store's compressed records decoded (bin/obs follow -decode). This file names no private word, so it is
# committed and the check runs on any host, a fresh clone's and the lab host's among them. The deny list LAUG_DENYLIST
# names, which check/denylist.sh reads, is grepped too where it is present, by its rule (internal/denylist).
#
# A line "except <expression>" takes a match that is all of <expression> off the hits, whichever shape matched it.
# Each shape is written so that it does not match its own line, so this file can be grepped with it.
#
# Most of a pack is binary, so each shape is 6 bytes or more and costs random bytes about 1 chance in 2^40 a byte or
# fewer (computed): a shape that random bytes match would refuse every pack. Left out for that reason: a time zone's
# 3 letters, a 12-digit account id (the last group of a random UUID is 12 digits about once in 280, computed), an
# email address in general.

# A home directory, with a user name after it.
/hom[e]/[A-Za-z0-9_]
/User[s]/[A-Za-z0-9_]
/roo[t]/

# The host name an EC2 instance has unless it is set, and its internal domain names. Source: the EC2 User Guide,
# "Amazon EC2 instance hostname types" (an IP name: ip-, the private IPv4 address with hyphens, then the domain).
i[p]-[0-9]{1,3}-[0-9]{1,3}-[0-9]{1,3}-[0-9]{1,3}
\.compute\.interna[l]
\.ec2\.interna[l]

# An EC2 instance id, an AWS access key id, an ARN. Source: the EC2 User Guide, "Resource IDs" (i- and 17 hex digits);
# the IAM User Guide, "IAM identifiers" (a long-term access key id: AKIA and 16 more, 20 characters) and "IAM ARNs".
[i]-[0-9a-f]{17}
AKI[A][0-9A-Z]{16}
ar[n]:aws:

# Key material, as a PEM file's BEGIN and END lines label it. Source: RFC 7468, section 10.
PRIVATE KE[Y]

# A GitHub identity, the no-reply address a commit's author can carry. Source: GitHub's page on commit email addresses.
@users\.noreply\.github\.co[m]

# An IPv4 address, but for the three the stack and its cells write: 127.0.0.1, 0.0.0.0, and a microVM cell's
# host-only 10.254.<block>.2.
[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}
except 127\.0\.0\.1
except 0\.0\.0\.0
except 10\.254\.[0-9]{1,3}\.2
